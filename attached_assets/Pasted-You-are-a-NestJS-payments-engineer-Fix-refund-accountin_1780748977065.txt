You are a NestJS payments engineer. Fix refund accounting that can
over-deduct a vendor's payout by the service fee portion.

CONTEXT:
When a full refund is issued, the current refund logic calculates
the vendor clawback as a percentage of the total refund amount.
The order total includes the service fee (which the vendor never
received — it is Feastpot platform revenue). If the clawback is
based on total, the vendor is deducted for money they never had.

Example of the bug:
  Order subtotal:       £40.00
  Service fee (5%):     £2.00  ← Feastpot keeps this
  Delivery fee:         £2.49  ← Vendor keeps this
  Total:                £44.49

  Full refund issued:   £44.49 (customer gets all their money back — correct)

  WRONG clawback:  £44.49 × 88% = £39.15 deducted from vendor
  CORRECT clawback: £40.00 − commission + £2.49 delivery = £38.29
                    (vendor loses what they earned, not what the customer paid)

  Over-deduction: £39.15 − £38.29 = £0.86 per order
  At 100 orders/week with full refunds: ~£86/week wrongly deducted from vendors

NOTE: The RED-001 payout formula fix does not make this worse —
it was a latent issue before. But it must be resolved before
refunds are issued at any volume.

STEP 1 — Fix full refund clawback formula
File: apps/api/src/modules/payments/payments.service.ts

The correct clawback when a full refund is issued:

// ─────────────────────────────────────────────────────────────────
// REFUND CLAWBACK FORMULA — DO NOT CHANGE WITHOUT FINANCE SIGN-OFF
//
// When a customer receives a full refund:
//   - Customer gets back: subtotal + serviceFee + delivery - discount
//   - Vendor loses:       subtotal + delivery - discount - commission
//   - Feastpot loses:     commission (it already kept the serviceFee
//                         when the order was placed, so it refunds
//                         the serviceFee from its own pocket to the
//                         customer — Feastpot absorbs the serviceFee
//                         on refunds, this is standard platform practice)
//
// The key rule: vendorClawbackPence must be based on
// (subtotalPence + deliveryFeePence - discountPence - commissionPence)
// NOT on (totalPence × some percentage)
// ─────────────────────────────────────────────────────────────────

async issueFullRefund(orderId: string, initiatedBy: string) {
  const order = await this.prisma.order.findUnique({
    where:   { id: orderId },
    include: { payment: true, vendor: true },
  })

  if (!order) throw new NotFoundException('Order not found')

  // 1. Issue full refund to customer via Stripe
  const refund = await this.stripe.refunds.create({
    payment_intent: order.payment.stripePaymentIntentId,
    // Refunds the full captured amount (subtotal + serviceFee + delivery - discount)
  })

  // 2. Calculate correct vendor clawback
  // Vendor clawback = what they were paid = subtotal + delivery - discounts - commission
  // Do NOT include serviceFeePence — vendor never received it
  const vendorClawbackPence =
    order.subtotalPence
    + order.deliveryFeePence
    - order.discountPence
    - order.commissionPence

  // 3. Deduct from next vendor payout
  await this.prisma.payout.updateMany({
    where: {
      vendorId: order.vendorId,
      status:   { in: ['draft', 'pending'] },
    },
    data: {
      refundsPence: { increment: vendorClawbackPence },
      // The payout batch will subtract refundsPence from the gross
    },
  })

  // 4. Record the refund
  await this.prisma.payment.create({
    data: {
      orderId:               order.id,
      userId:                order.customerId,
      type:                  'refund',
      status:                'succeeded',
      amountPence:           order.totalPence,  // full customer refund amount
      stripeRefundId:        refund.id,
      processedAt:           new Date(),
    },
  })

  // 5. Write audit log
  await this.prisma.auditLog.create({
    data: {
      actorId:    initiatedBy,
      action:     'refund_issued',
      entityType: 'Order',
      entityId:   order.id,
      metadata: {
        customerRefundPence: order.totalPence,
        vendorClawbackPence,
        serviceFeePenceAbsorbed: order.serviceFeePence,
        commissionRefunded:      order.commissionPence,
      },
    },
  })

  return { refund, vendorClawbackPence }
}

STEP 2 — Fix partial refund clawback formula
File: apps/api/src/modules/payments/payments.service.ts

For partial refunds, the clawback must be proportional to the
food subtotal only, not to the total:

async issuePartialRefund(
  orderId:      string,
  refundPence:  number,
  initiatedBy:  string,
  reason:       string,
) {
  const order = await this.prisma.order.findUnique({
    where: { id: orderId },
  })

  // For a partial refund, calculate what fraction of the food
  // subtotal is being refunded — then apply that fraction to
  // the vendor clawback (not the total)
  //
  // Example: customer paid £44.49, refunding £20.00
  // That refund covers ~50% of the food subtotal (£20/£40)
  // Vendor clawback = 50% × (subtotal + delivery - discounts - commission)

  const refundFraction = Math.min(
    refundPence / order.subtotalPence,
    1  // cap at 100%
  )

  const vendorClawbackPence = Math.round(
    refundFraction * (
      order.subtotalPence
      + order.deliveryFeePence
      - order.discountPence
      - order.commissionPence
    )
  )

  // Issue Stripe partial refund
  const refund = await this.stripe.refunds.create({
    payment_intent: order.payment.stripePaymentIntentId,
    amount:         refundPence,
  })

  // Deduct from next payout
  await this.prisma.payout.updateMany({
    where: {
      vendorId: order.vendorId,
      status:   { in: ['draft', 'pending'] },
    },
    data: { refundsPence: { increment: vendorClawbackPence } },
  })

  // Record
  await this.prisma.payment.create({
    data: {
      orderId:        order.id,
      userId:         order.customerId,
      type:           'partial_refund',
      status:         'succeeded',
      amountPence:    refundPence,
      stripeRefundId: refund.id,
      processedAt:    new Date(),
    },
  })

  return { refund, vendorClawbackPence }
}
