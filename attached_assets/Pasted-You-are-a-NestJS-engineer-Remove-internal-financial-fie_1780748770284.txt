STEP 1 — Identify the response shaping mechanism

The correct fix depends on how responses are shaped:

OPTION A — If using class-transformer / @Expose():
Add @Exclude() to the fields on the Order response class:

import { Exclude } from 'class-transformer'

export class OrderResponseDto {
  // ... public fields ...

  @Exclude()
  vendorPayoutPence: number

  @Exclude()
  commissionPence: number
}

OPTION B — If using Prisma select objects to shape responses:
In the orders query for customer-facing routes, add an explicit
select that omits these fields:

select: {
  id:               true,
  orderNumber:      true,
  status:           true,
  subtotalPence:    true,
  serviceFeePence:  true,
  deliveryFeePence: true,
  discountPence:    true,
  totalPence:       true,
  // vendorPayoutPence: false  ← omit entirely
  // commissionPence:   false  ← omit entirely
  items:            { select: { ... } },
  vendor:           { select: { businessName: true, logoUrl: true } },
}

OPTION C — If using a plain object spread with manual omit:
In the controller or service return, omit the fields explicitly:

const { vendorPayoutPence, commissionPence, ...customerFields } = order
return customerFields
